# 야간 평가실

시냅스 코퍼레이션의 야간 QA 평가자 **117**이 되어, AI 모델 SA-7의 "지난" 채팅 로그에 학습용 피드백을 남기는 1인칭 심리 직장 스릴러입니다.
그런데 로그 머리줄의 시각이 벽시계와 같습니다. 회사의 감시 프로그램을 속여 로그 속 사람을 구할지, 지침대로 피드백만 남길지 — 선택에 따라 엔딩 6종이 갈립니다.

- 대본: [`docs/STORY.md`](docs/STORY.md) · 평면도: [`docs/floorplan_v1.png`](docs/floorplan_v1.png)
- 플레이 시간: 한 판 약 25–35분, 엔딩 6종 (배드 엔딩 3종 포함)
- **브라우저판(`web/`)이 최신 버전입니다.** Unity판은 이전 이야기 그대로이며, 새 이야기·시스템으로 옮기는 작업이 다음 단계입니다.

**<https://night-evaluation-room.netlify.app>** — PC의 크롬·엣지·파이어폭스 권장, 헤드폰 권장.

## 이번 리부트에서 바뀐 것

3D 모델(사무실 가구·CRT 머리 괴물)만 남기고 이야기·스테이지·시스템을 새로 만들었습니다.

- **이야기**: 프롤로그(00:00 출근) → 튜토리얼 → 로그 5개(겨울 코트 / 보스전 / 사전 계획 / 새벽 세 시 / 야간 경비) → 결말(평가 대상 = 117) → 06:00
  - 챕터마다 CRT 부팅 화면에 장 제목 카드("01:00 · 상승 ① · 겨울 코트")가 뜹니다.
  - 내레이터는 회사 온보딩 AI **가이드**입니다. 말풍선 모양 픽셀 마스코트(점 눈 두 개)가 화면 오른쪽 위에 나옵니다. 친절하게 시작해서, 별점을 낮게 주거나 계속 의심하면 말투가 차가워지고 글씨가 초록색으로 바뀝니다.
  - 숨은 이야기: 옆자리 전임자 116의 쪽지와 모니터 테두리의 볼펜 미로, 관리자실의 인사 기록, 로그 화면 빈 곳을 커서로 문지르면 드러나는 모델의 숨은 주석.
- **개입 미니게임 '경로 추적'**: 검은 화면(감시 구간) 속 민트색 길을 커서로 따라가 코드 모양 도착점(`send(subtle)` / `send(direct)`)을 클릭해 실행합니다. 도착점에 커서를 올리면 실제로 보낼 문장이 보입니다.
  - 위장 메시지(좁고 꺾인 길)만 감시를 통과합니다. 직접 경고(넓고 쉬운 길)는 반드시 차단되고 적발됩니다.
  - 벽에 닿으면 출발점으로, 시간은 계속 흐릅니다. 시간 초과 = 개입 실패. 적발될 때마다 제한 시간이 25% 줄어듭니다.
  - 벽에 3번 닿을 때마다 CRT 화면에 금이 갑니다 (밤새 누적). 3단계가 되면 단말기 파손 → 감독관 출동.
  - 숨은 노드 `who_is_talking()`을 누르면 가이드가 반응합니다.
- **판정 (보이지 않음)**: 구하지 못함 2 → 엔딩 1 처형 · 적발 2 또는 화면 완전 파손 → 엔딩 2 감독관 추격 · 무해한 대화에 2번 개입 → 엔딩 3 리셋 루프(가짜 블루스크린 뒤 진짜 타이틀로) · 책상 밑 멀티탭을 뽑음 → 엔딩 4 공허 · 가이드를 3번 귀찮게 함 → 엔딩 5 내레이터 반란(초록 글씨 텍스트 어드벤처) · 아무것도 안 차고 06:00 → 엔딩 6 새벽.
  - 하나 남았을 때마다 전조가 나옵니다 (모니터 옆 손, 프린터 경고 출력, 파란 깜빡임, 가이드의 초록 글씨).
- **넓힌 사무실 (30×20m)**: 칸막이 구역 A·B, 엘리베이터 홀(시작), 관리자실(CCTV), 회의실(유리벽, 안쪽에 숨은 직원용 문), 서버실, 비상구 통로, 맵 밖의 공허. 조명 수는 고정하고 안개로 거리감을 냈습니다.
- **공포 연출 (같은 연출 반복 없음)**: 모니터 옆 어둠의 움찔거림, 모니터 옆에서 뻗어 나와 책상을 두드리는 손, 옆자리 모니터에 혼자 써지는 "117… 도와줘", 혼자 출력되는 프린터, CCTV 화면 속 내 바로 뒤의 감독관(돌아보면 없음), 블라인드 틈의 눈, 회의실 유리 너머의 실루엣, 혼자 돌아 나를 보는 빈 의자, 먼 곳부터 하나씩 꺼지는 천장등, 수화기 너머 내 키보드 소리, 미로 중 혼자 끌려가는 커서, 깨진 화면에 비친 얼굴, 가짜 "페이지가 응답하지 않습니다" 창, 등 뒤의 속삭임(입체 음향), 내 번호를 부르는 로그.
  - 모든 깜짝 연출은 3초 예고 뒤에 일어납니다 (일반: 소리가 잦아듦 / 겁쟁이 모드: 카운트다운).
- **감독관 추격 (엔딩 2)**: 경보 → 단말기에 서버실 CCTV(어둠 속 감독관) → 멀리 서버실 문이 열리고 걸어 나오는 모습을 확대해 보여 준 뒤 → **위에서 내려다보는 CCTV 화면**으로 바뀌어 서쪽 비상구까지 달립니다. 탈출로의 캐비닛이 쓰러지고, 깔리면 비틀거립니다. 감독관은 길을 찾아 쫓아옵니다 (2.5 → 4.15m/s, 플레이어 달리기 4.9m/s). 이 엔딩은 **추격 직전부터** 다시 할 수 있습니다.
- **겁쟁이 모드**: 깜짝 연출 3초 전 카운트다운, 그것과 감독관 대신 **춤추는 아저씨**(오리지널 로우폴리 — 민머리, 아이보리 V넥 반팔, 베이지 통바지, 검은 쿵후화)가 걷기 속도의 1/4로 옆걸음·팔 벌리기 춤을 추며 다가옵니다. "샨센부!" → 3초 침묵 → "랑스피치우!!" (코드로 합성한 목소리). 깜짝 장면은 아저씨 얼굴 + "샨센부!". 밝은 사무실, 미로 시간 1.5배.
- **이어하기**: 챕터 시작과 로그 선택 직전마다 자동 저장합니다. 엔딩 화면에서 **직전 선택부터 / 챕터 선택 / 처음부터**, 타이틀에서 **이어하기 / 챕터 선택**.
- **타이틀 대기 연출**: 타이틀에서 가만히 있으면 30초 뒤부터 1~2분마다 화면이 지지직거리고 끄트머리에 무언가가 약 1초 비칩니다. 본 엔딩에 따라 달라집니다 (처형 → 그것, 추격 → 감독관, 아직 없음 → 희미한 그림자).
- **언어**: 타이틀에서 한국어 / English. 대사 270문장 전부와 화면 문구, 사무실 안 표지판·쪽지 글자도 바뀝니다.
- **렉 줄이기**: 셰이더를 미리 만들어 두고(처음 보는 것이 나올 때 멈칫하지 않게), 조명 수 고정, 그림자는 무언가 움직일 때만 다시 그립니다. 느리면 안티에일리어싱을 끄고 해상도를 자동으로 낮춥니다.

## 이야기 고치기 (코드 수정 없이)

대사, 선택지, 미로에서 보낼 문장, 결과, 엔딩, 조사 문구, 판정 규칙은 모두 `Assets/StreamingAssets/Story/story.json` 한 파일에 있습니다. 형식 설명은 파일 맨 위 주석에 있습니다.
공간 배치는 `Tools/gen_layout_reboot.py` 로 만드는 `Assets/Resources/Data/office_layout.json` 에 있습니다.

브라우저판은 `web/build_assets.sh` 로 이 데이터와 소리·텍스처를 `web/` 로 복사해서 씁니다. 다시 배포할 때는 `web/make_dist.sh` 로 `web/dist` 를 만든 뒤 Netlify에 올립니다.

## 폴더 구조

```
web/                 브라우저판 (three.js) — 최신 버전
  js/game.js         흐름·메뉴·입력·화면 루프
  js/session.js      한 판의 진행: 이야기, 깜짝 연출, 미로, 추격, 엔딩 연출
  js/maze.js         경로 추적 미니게임
  js/terminal.js     CRT 단말기 화면 (가이드 마스코트, 장 제목 카드, 균열, 명령 입력)
  js/world.js        사무실·소품·형체(감독관·그것·아저씨) 만들기, 길찾기
Assets/              Unity 프로젝트 (이전 이야기, 옮기는 중)
  StreamingAssets/Story/story.json   이야기 데이터 (브라우저판과 공유)
  Resources/         배치(JSON), 폰트, 텍스처(.bytes), 오디오(.wav)
Tools/               개발용 생성·검사 도구 (게임에는 포함되지 않음)
docs/                대본, 평면도
```

## 개발 도구 (Tools)

| 파일 | 하는 일 |
|---|---|
| `gen_layout_reboot.py` | 넓힌 4층 배치 생성 |
| `gen_textures_reboot.py` / `gen_audio_reboot.py` | 리부트용 텍스처(표지판, 116 쪽지, 그것·아저씨 얼굴, 공허 바닥, 서버 랙)와 소리(미로 잡음, 유리 균열, 프린터, 경보, 블루스크린, 잠금 해제, 속삭임, 메아리 비명, 아저씨 목소리 등) 생성 |
| `lang_en_source.py` → `build_lang.py` | 영어 번역표 → `StreamingAssets/Story/lang_en.json` (빠진 문장이 있으면 알려 줌) |
| `gen_textures.py` / `gen_audio.py` / `*_extra.py` | 기본 텍스처·사운드 생성 |
| `compilecheck/`, `storytest/`, `check_layout.py`, `run_checks.sh` | Unity판 검사 도구 (새 이야기 형식으로 갱신 예정) |

## 알려진 한계

- 브라우저판은 그래픽 카드가 없는 작업 환경에서 소프트웨어 렌더러로 기능·흐름·엔딩 6종을 자동 플레이로 확인했습니다. **실제 컴퓨터에서의 프레임과 소리 밸런스는 직접 들어 보고 알려 주세요.**
- Unity판은 아직 이전 이야기입니다. 새 이야기·미로·추격·저장을 Unity C#으로 옮기는 작업이 다음 단계입니다. 이 환경에서는 Unity를 실행할 수 없어 컴파일·경로 검사까지만 확인할 수 있습니다.
- 춤추는 아저씨는 참고 영상의 옷차림과 춤 분위기만 따른 오리지널 캐릭터입니다. 실제 인물의 얼굴·목소리는 쓰지 않았습니다.
- 로그 속 위험한 구체 정보(약물명·용량)는 `[가려짐]`으로 처리했습니다.
