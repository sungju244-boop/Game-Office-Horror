# 야간 평가실 (MVP)

AI 회사의 계약직 **야간 안전성 평가자 117**이 되어, 어두운 사무실에서 AI 대화 기록을 평가하는 1인칭 심리 공포 게임입니다.
기록을 읽고 판단하면 사무실이 바뀌고, 자리에서 일어나 확인해야 다음 기록이 옵니다. 그러다 마지막 평가 대상이 자기 자신이라는 걸 알게 됩니다.

- 엔진: **Unity 6.3 LTS** (Built-in 렌더 파이프라인), PC
- 공포는 빈 공간, 문, 조명, 소리, 감시로 쌓아 올립니다. **브라우저판**에는 괴물 추격과 깜짝 장면이 있고, 무서우면 **겁쟁이 모드**로 줄일 수 있습니다. (Unity판은 아직 이전 버전: 깜짝 장면 없음, 추격자는 고양이)
- 플레이 시간: 한 번에 약 20–30분. 결정 8회, 엔딩 6종 (배드 엔딩 3종 포함)

---

## 바로 플레이 (브라우저, 설치 없음)

**<https://night-evaluation-room.netlify.app>** — PC의 크롬·엣지·파이어폭스 권장, 헤드폰 권장.

브라우저판에만 있는 것 (Unity판에는 아직 없음):

- **언어**: 타이틀에서 한국어 / English 전환. 사무실 안의 공지문·사원증·쪽지·표지판 글자도 함께 바뀝니다. 처음에는 브라우저 언어를 따릅니다.
- **괴물·깜짝 장면**: 추격자는 키 2.3m, 깨진 CRT 머리의 괴물입니다. 깜짝 장면은 조명 패널, 감독석 CCTV, 입구 문, 꺼진 모니터, 추격 시작, 그리고 잡혔을 때. 깜짝 장면 직전 3초 동안은 소리가 잦아듭니다.
- **겁쟁이 모드**: 켤 때 경고가 뜹니다. 모든 깜짝 장면 3초 전에 오른쪽 아래 카운트다운, 괴물 대신 우이이아이오 고양이, 밝은 사무실, 귀여운 배경음. 타이틀이나 일시정지 → 설정에서 바로 켜고 끌 수 있습니다.
- **엔딩 앨범**: 엔딩을 하나 보면 타이틀에 나타납니다. 찾은 엔딩은 다시 읽기, 못 찾은 엔딩은 힌트 보기.
- **렉 줄이기**: 화면이 느려지면 안티에일리어싱을 끄고 해상도를 자동으로 낮춥니다. 셰이더를 미리 만들어 두어 괴물이 처음 나올 때 멈칫하지 않고, 그림자는 무언가 움직일 때만 다시 그립니다.

브라우저판 코드는 `web/` 에 있고, 이야기·배치·소리·텍스처는 Unity판과 같은 데이터를 씁니다 (`web/build_assets.sh` 로 복사).
다시 배포할 때는 `web/make_dist.sh` 로 `web/dist` 를 만든 뒤 Netlify에 올립니다.

## 플레이 방법 — Unity판 (처음 한 번만)

1. **Unity Hub** 설치: <https://unity.com/download>
2. Hub → **Installs → Install Editor → Unity 6000.3.27f2 (6.3 LTS)** 설치
   - 추가 모듈은 필요 없습니다 (지금 쓰는 OS용 빌드는 기본 포함).
3. 이 저장소를 내려받습니다 (GitHub에서 **Code → Download ZIP** → 압축 풀기).
4. Hub → **Projects → Add → Add project from disk** → 압축을 푼 폴더 선택 → 프로젝트 열기
   - 처음 열면 몇 분 동안 가져오기를 합니다. "누락된 에디터 버전" 창이 뜨면 이미 설치한 6000.3 버전을 골라 열면 됩니다 (같은 6.3 안에서는 호환됩니다).
   - 열리면 자동으로 `Main` 씬을 만들고 필요한 설정을 합니다.
5. 화면 위쪽 가운데 **▶ (Play)** 를 누르면 게임이 시작됩니다.

실행 파일(.exe)이 필요하면 상단 메뉴 **야간 평가실 → 실행 파일 만들기 (현재 OS)** 를 누르세요. 완료되면 `Builds/` 폴더가 열립니다.

> 혹시 빨간 오류가 나오면 Unity 아래쪽 **Console** 창의 내용을 그대로 복사하거나 스크린샷을 찍어 전달해 주세요.

## 조작

| 키 | 동작 |
|---|---|
| WASD / 방향키 | 이동 |
| Shift | 달리기 |
| 마우스 | 시점 |
| E | 상호작용 (컴퓨터 사용, 문, 조사) |
| 단말기에서 클릭 / Space | 대사 넘기기, 선택지 고르기 |
| 단말기에서 마우스 휠 | 이전 대사 보기 |
| ESC | 단말기에서 일어나기 / 일시정지 메뉴 |

일시정지 메뉴에서 **설정(밝기·전체 음량·배경음·마우스 감도)**, **처음부터 다시**, **타이틀로** 를 쓸 수 있습니다.

## 이번 버전에 들어간 것

- **공간**: 낮은 천장의 낡은 사무실(14×10m), 뒤쪽 복도와 비상구, 입구 앞 엘리베이터 홀. 꺼진 CRT 모니터가 놓인 책상 줄, 파티션, 캐비닛, 정수기, 감독석, 천장 CCTV, 블라인드 친 창문(달빛 줄무늬 그림자), 천장과 바닥에 늘어진 케이블
- **단말기**: 별도 UI 창 없이 **CRT 모니터 화면에 직접** 글자가 뜹니다. 큰 대사, 큰 2지선다. 곡률·주사선·잡음이 있고, 불안한 선택지는 마우스를 올리거나 고르면 글자와 화면이 지지직거립니다.
- **이야기**: 기록 6개 (닫히지 않은 창문 / 기록에 없는 사용자 / 4층 / 평가 기준 / 평가자에게 / 최종 평가)
  - 평가 선택은 매번 **「피드백만 기록」/「보호 개입 요청」**. 피드백만 남기면 사건이 방치되는 쪽으로, 개입을 요청하면 회사의 감시와 통제가 강해지는 쪽으로 사무실이 바뀝니다.
  - 상황 선택(답장할지, 대답할지, 메모를 닫을지 등)이 후속 메시지와 엔딩에 반영됩니다.
  - 최종 평가 파일은 **플레이어가 실제로 한 선택과 확인하러 가는 데 걸린 시간**을 인용합니다.
- **핵심 루프**: 기록 읽기 → 판단 → 사무실 변화(문, 잠금, 조명, 소리, CCTV, 모니터) → **일어나서 직접 확인** → 다음 기록.
  소리 단서에는 항상 화면 자막이 함께 나옵니다.
- **추격**: 마지막에 계약 종료를 거부하면 무언가가 입구로 들어옵니다. 지금 외형은 **빙글빙글 도는 회색 고양이(우-이-이-아-이-오)** 입니다. 잡히면 비명 없이 암전됩니다. 이 엔딩에서는 **추격 직전부터 다시** 할 수 있습니다.
- **엔딩**: 검은 화면에 `ENDING n — 제목`과 117이 어떻게 되었는지 몇 줄이 나옵니다 (6종). 타이틀에 찾은 엔딩 수가 표시됩니다.
- **소리**: 배경음, 환경음(형광등, 냉각팬, CRT, 외풍), 효과음 등 62개를 전부 코드로 합성했습니다. 외부 음원은 쓰지 않았습니다. 깜짝 장면용 비명·포효 몇 개(최대 −1.5 dBFS)를 빼면 최대 음량은 −6 dBFS 이하입니다.
- **그래픽**: 모델 30여 종과 텍스처 39종(영어 글자판·괴물·고양이 포함)을 모두 코드로 만들었습니다 (저해상도·로우폴리). 한글은 픽셀 폰트 **Galmuri**를 씁니다.

## 이야기 고치기 (코드 수정 없이)

대사, 선택지, 결과, 엔딩, 조사 문구는 모두 `Assets/StreamingAssets/Story/story.json` 한 파일에 있습니다.

- Unity 메뉴 **야간 평가실 → 스토리 데이터 폴더 열기** 로 바로 찾을 수 있습니다.
- 빌드한 게임에서는 `…_Data/StreamingAssets/Story/story.json` 을 고치면 다시 빌드하지 않아도 반영됩니다.
- 형식 설명은 파일 맨 위 주석에 있습니다. 고친 뒤 `Tools/run_checks.sh` 를 실행하면 모든 경로가 엔딩까지 이어지는지 확인합니다.

공간 배치는 `Assets/Resources/Data/office_layout.json` 에 있습니다.

## 폴더 구조

```
Assets/
  Game/Scripts/      게임 코드 (Core, Story, World, Player, Terminal, Director, UI, Rendering)
  Game/Editor/       처음 열 때 자동 설정 + 빌드 메뉴
  StreamingAssets/Story/story.json   이야기 데이터
  Resources/         배치(JSON), 폰트, 셰이더, 텍스처(.bytes), 오디오(.wav)
Tools/               개발용 검사·생성 도구 (게임에는 포함되지 않음)
web/                 브라우저판 (three.js) — 같은 데이터 사용
```

## 개발 도구 (Tools)

| 파일 | 하는 일 |
|---|---|
| `run_checks.sh` | 아래 검사 전부 실행 |
| `compilecheck/` | Unity 참조 DLL로 C# 스크립트 컴파일 검사 |
| `storytest/` | 게임과 같은 이야기 코드로 모든 선택 경로를 끝까지 시뮬레이션 |
| `check_layout.py` | 위에서 본 지도를 그리고, 플레이어 반지름 기준으로 모든 확인 지점·비상구까지 갈 수 있는지 검사 |
| `check_font.py` | 게임에 쓰인 모든 글자가 폰트에 있는지 검사 |
| `gen_textures.py` / `gen_audio.py` | 텍스처·사운드 생성 (다시 만들 때) |
| `gen_textures_extra.py` / `gen_audio_extra.py` | 영어 글자판, 괴물·고양이 얼굴, 괴물·깜짝 장면·귀여운 배경음 생성 |
| `lang_en_source.py` → `build_lang.py` | 영어 번역표 → `StreamingAssets/Story/lang_en.json` (빠진 문장이 있으면 알려 줌) |

## 알려진 한계

- 이 저장소는 **Unity를 실행할 수 없는 클라우드 환경**에서 만들었습니다. 컴파일, 이야기 경로, 공간 경로, 폰트는 위 도구로 검사했습니다. 하지만 **Unity 에디터에서의 실제 실행, 셰이더 컴파일, 조명 밝기, 프레임, 실행 파일 빌드는 아직 확인하지 못했습니다.** 처음 실행하면서 문제가 보이면 알려 주세요.
  - 컴파일 검사는 Unity 2021 API 참조 DLL과 uGUI 스텁으로 했습니다. Unity 6 전용 차이는 실제 에디터에서만 확인할 수 있습니다.
- 3D 모델 사이트(Kenney, Poly Haven 등)가 작업 환경 네트워크에서 막혀 있어, 모델은 코드로 만들었습니다. `Resources/Models/CrtMonitor`, `Resources/Models/OfficeChair` 프리팹을 넣으면 그 모델이 대신 쓰입니다.
- Unity판의 추격자는 아직 테스트용 고양이입니다. 외형만 바꾸면 그대로 괴물로 교체할 수 있습니다 (`PropFactory.Cat`).
- 브라우저판은 그래픽 카드가 없는 작업 환경에서 소프트웨어 렌더러로 기능·흐름만 확인했습니다. **실제 컴퓨터에서의 프레임은 측정하지 못했습니다.**
